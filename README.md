## Features

- **Hero Section** — Animated typed text introduction with dynamic role display
- **About** — Personal biography, profile image, and background details
- **Resume** — Education and professional experience timeline
- **Portfolio** — Project showcase gallery with lightbox previews
- **Contact** — Functional contact form powered by PHP
- **Responsive Design** — Fully mobile-friendly layout using Bootstrap grid
- **Smooth Animations** — Scroll-based animations with AOS (Animate On Scroll)
- **Image Gallery** — Swiper.js powered carousel for portfolio items

## Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/gautammanak1/MyPortfolio.git
   cd MyPortfolio
   ```

2. **Open locally**

   Open `index.html` in your browser, or use a local server:

   ```bash
   npx serve .
   ```

3. **Contact form** requires a PHP-enabled server to process form submissions.

## Usage

- Navigate through sections using the sidebar menu
- Click portfolio items to view full-size images in lightbox
- Use the contact form to send messages
- Social links in the sidebar connect to Twitter, GitHub, Instagram, WhatsApp, and LinkedIn
